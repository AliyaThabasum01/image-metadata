# 🖼️ Image Metadata

A lightweight Python CLI tool that displays basic metadata of an image.

## Features

- Detect image format
- Display width and height
- Show color mode
- Display file size
- Simple CLI interface

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Example

```text
Enter image path: photo.jpg

🖼️ Image Metadata
===================================

File        : photo.jpg
Format      : JPEG
Width       : 1920
Height      : 1080
Mode        : RGB
Size        : 245.67 KB
```

## Built With

- Python
- Pillow
